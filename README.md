# WEB BIS Dashboard

React dashboard for the Node.js + MySQL backend.

## Run

1. Install dependencies:
   - `npm install`
2. Create env:
   - copy `.env.example` to `.env`
3. Start:
   - `npm run dev`

Default URL: `http://localhost:5173`

## Deploy

GitHub Pages URL:

```txt
https://deka217.github.io/dashboard_web_bis/
```

Build and deploy:

```sh
npm run deploy
```
